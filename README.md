# 🔞또또NSFW

## v0.13.13 수정

- `scene_state`와 `sfw_scene`를 답변 표시 전에 숨겨. 스트리밍 중 미완성 태그, 코드 블록과 HTML 이스케이프 형태도 처리해. 화면에서 제거하려고 먼저 원문을 지우지 않아서 완료된 답변의 기록 수집은 유지해.
- 메시지 표시 훅이 있는 버전에서는 훅을 사용하고, 정식 버전에는 표시 전용 Regex 규칙을 등록해. Regex를 꺼 둔 환경이나 번역 확장의 직접 화면 갱신은 채팅 표시 노드에서 호환 처리해. 사용자·시스템 메시지와 일반 JSON/코드 블록은 유지해.
- 기존 사용자 Regex 규칙을 변경하지 않고, 확장을 끄면 이 확장의 숨김 규칙만 제거해. 단독 사용과 재활성화에도 중복 등록하지 않아. 별도 AI 호출 없이 동작해.
- 브라우저에서 스트리밍·선택 스와이프·화면 서식·태그를 숨긴 뒤의 상태 수집을 확인했고, 기존 감지·인계·기록 테스트도 통과했어. 실제 사용자 ST 설치 환경의 모든 타사 확장 조합을 확인한 것은 아니야.
- 두 확장을 사용하는 경우 또또SFW v0.2.30와 함께 교체하고 새로고침해줘.

## v0.13.9 수정

## 어떻게 동작해?

### 평소 (일상 장면) — 완전 침묵 (스텔스, 기본)

프롬프트 주입 **제로**, AI 호출 **제로**, 흔적 **제로**.
확장이 브라우저 안에서 현재 유저 행동과 직전 응답을 직접 스캔하며, 신체 명칭이나 과거 장면의 잔여물이 아니라 **지금 진행 중인 성적 행동**을 점수로 매겨. 일상 장면에는 아무것도 안 하고, 현재 행동 신호가 양쪽에서 사라지면 빠르게 또또SFW로 인계해.

감지 민감도(민감/보통/둔감)를 고를 수 있고, 자주 쓰는 표현을 커스텀 키워드로 추가하면 감지가 더 정확해져.
모델이 온도를 직접 보고하게 하는 "온도 자동" 모드(매턴 한 줄 요청)도 옵션으로 있어. 이 모드도 본문 신호를 함께 확인하므로 낮은 보고 온도만으로 현재 성적 행동의 감지를 취소하지 않아. 온도는 응답 끝의 실제 장면을 기준으로 `0~1 일상 / 2 가벼운 호감 / 3~4 키스·밀착 / 5~6 성적 접촉·전희 / 7~8 명시적 행위 / 9 절정 직전 / 10 정점·종료 직전`으로 판정해.

### 장면이 달아오르면 — 자동 개입

1. NSFW 신호가 기준을 넘는 순간 자동 무장. 보조 AI 자동 보정이 켜져 있으면 최근 대화를 읽어 장소·복장·자세·접촉을 보충하고, 꺼져 있으면 다음 메인 답변의 상태 태그로 정보를 수집해.
2. 매 생성마다 프롬프트에 주입:
   - **현재 장면 상태** (모순 금지: 벗은 옷 부활 금지, 순간이동 금지)
   - **최근 N턴 전개 목록** (말만 바꿔서 반복해도 반복임)
   - **다음 전개 힌트** (AI가 스스로 제안한 새 전개 후보)
   - **진행 지시** (유지 / 자연스럽게 다음 단계 / 적극적으로)
3. AI 응답 끝의 `<scene_state>` 블록을 파싱해 저장하고 화면에서는 제거
4. 장면이 식으면 (온도 2↓) 다시 초경량 감시로 복귀

### 💬 대사 전개 반복 방지

전개(행위) 반복 금지와 별개로, 캐릭터가 **대사로 하는 일**이 반복되는 것도 막아줘. 모델이 상태 태그에 `dialogue_beats`(예: "쾌감 확인 질문", "더 해달라고 조름", "같은 칭찬")를 적어주면, 최근 N개 AI 답변에서 쓴 의도를 "말만 바꿔서 반복하지 마" 목록으로 주입해.

- 문장 표현이 아니라 **대사의 목적**을 막아. 표현 반복은 원래 또또의 몫이야.
- 범위는 설정에서 1~6개 답변으로 조절 (기본 2). 넓힐수록 같은 대사 기능이 오래 안 돌아와.
- 유저 질문에 대한 직접 대답, 동의·안전 확인, 의미 있는 후렴구는 예외로 허용돼.
- 태그에 `dialogue_beats`가 빠져도 그것 때문에 보조 AI 호출이 나가진 않아 (다른 필드가 비었을 때 보정하면 같이 채워져).
- 0.13.0부터 개발자 모드가 아니라 일반 설정에 있어. 신규 설치는 기본 켜짐, 기존 설정값은 그대로 유지돼.

### 🧩 CardInject 연동 (선택 기능)

CardInject 확장으로 분석해둔 캐시트 카테고리 중 고른 것을 **다음 전개 힌트의 참고 자료**로 써.

- 설정 → **🧩 CardInject 연동**을 켜고, 목록에서 참고시킬 카테고리를 체크해. (이름이 성향·취향 같아 보이는 건 ★ 표시)
- **개입 중일 때만** 주입돼. 평소(스텔스 대기)엔 아무것도 안 들어가.
- 다음 전개 힌트가 켜져 있어야 동작해. 목표 장면 진행 중에는 주입하지 않아.
- 참고 자료일 뿐이야. "강요하지 말 것, 현재 장면 상태·하드 리밋·유저 금지를 어기지 말 것"이 같이 붙어.
- 보조 AI 보정 호출은 캐시트를 못 보기 때문에, 보정할 때도 같은 참고 자료를 같이 넘겨서 `next` 제안에 반영시켜.
- **중복 주입 주의**: CardInject에서도 켜져 있는 카테고리는 프롬프트에 두 번 들어가. CardInject에서 그 카테고리를 끄면(내용은 남아 있어) 이 확장이 개입 중일 때만 주입하는 식으로 쓸 수 있어. 목록에 카테고리별 켜짐 상태와 중복 경고가 떠.
- CardInject 쪽은 읽기만 하고 건드리지 않아. 참고 자료는 최대 2500자까지만 들어가.

### 🔥 슬로우번 (선택 기능)

설정에서 슬로우번을 켜면 기존의 한 줄짜리 진행 속도 지시 대신 6단계 진행 관리가 적용돼.

1. 긴장과 분위기 형성
2. 시선·말·거리 좁히기
3. 가벼운 접촉
4. 접촉과 반응 심화
5. 본격적인 전개
6. 마무리 허용

- 강도에 따라 슬로우번을 켠 순간부터 최소 1·2·3개의 새 AI 답변을 세고, 각 단계에도 같은 답변 수만큼 머문 뒤 자연스러울 때만 다음 단계로 넘어가
- 한 답변에서 한 단계 이상 건너뛰거나, 중간 과정을 생략·요약하거나, 6단계 전에 임의로 장면을 끝내지 않게 지시해
- 최소 턴을 채우기 전에는 이미 6단계로 감지되어도 장면 종료·마무리·애프터로 넘어갈 수 없어
- 모델이 먼저 장면을 끝내 온도가 내려가도 개입을 해제하지 않고, 다음 응답에서 마지막 활성 장면을 이어가도록 복구 지시를 넣어
- 같은 행동을 늘여 쓰는 방식이 아니라 새로운 대사·감정·반응·감각을 쌓도록 지시해
- 장면 상태 탭에서 현재 단계를 이전·다음으로 조절하거나 고정할 수 있고, 다시 자동 감지로 돌릴 수 있어
- "사용자 주도 전개 허용"이 켜져 있으면 사용자가 먼저 명확하게 진행한 행동은 단계 제한보다 우선하지만, 최소 턴 잠금과 종료 금지는 그대로 유지돼

슬로우번을 끄면 기존 진행 속도 설정(자동/유지/자연스럽게/적극적으로)이 그대로 동작해.

수동 모드로 바꾸면 채팅 토글이 곧 개입 스위치가 돼.

해제 브릿지를 켜두면 온도 보고나 사용자의 직접 조작으로 개입을 끈 경우 다음 생성 한 번에만 여운·감정·작은 행동을 잇는 마무리 지시가 들어가. 현재 행동 신호가 이미 사라져 일상 장면으로 넘어간 경우에는 브릿지를 다시 넣지 않고 바로 SFW로 인계해.

### 주입은 영어, 화면은 한국어

모델이 상태 값을 `"English || 한국어"` 쌍으로 보고해서, 프롬프트 주입에는 영어만(지시 이행률·토큰 효율), 확장 패널 표시에는 한국어만 쓰여.

## 장면 상태 탭

- **현재 장면 상태**: 장소·인물별 복장·자세·접촉 + 온도 배지. 직접 수정하면 다음 생성부터 바로 반영
- **최근 전개**: 반복 금지 목록. ×를 누르면 그 항목만 금지에서 제외
- **최근 대사 전개**: 대사 반복 방지가 켜져 있을 때, 최근 쓴 대사 의도 목록. ×로 그 항목만 금지에서 제외
- **다음 전개 후보**: AI가 제안한 새 전개 (파란 칩). ×로 제안에서 제외 가능
- **상태 다시 분석**: 보조 AI로 상태를 수동 재구성
- **주입문 보기 / 기록 비우기**
