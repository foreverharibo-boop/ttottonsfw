# 🔞또또NSFW

NSFW 장면의 연속성을 지키고, 직전에 한 걸 또 하지 못하게 막고, 진도를 나가게 만드는 SillyTavern 확장이야.
[또또](https://github.com/foreverharibo-boop/ttotto)의 자매 확장이지만 따로 설치해서 단독으로 동작해.

**성인(만 18세 이상) 캐릭터 전용이야.** 설정에서 "모든 캐릭터는 성인입니다" 확인에 체크해야 동작해.

---

## 왜 필요해?

NSFW 장면에서 AI가 자주 저지르는 짓들:

- 벗긴 옷이 다음 턴에 다시 입혀져 있음
- 자세·위치가 물리적으로 말이 안 되게 순간이동함
- 방금 한 행위를 다음 턴에 처음 하는 것처럼 또 함
- 같은 자리를 맴돌다가 장면이 흐지부지 끝남

또또NSFW는 이 네 가지를 한 번에 잡아.

---

## 어떻게 동작해? (하이브리드)

1. **상태 추적** — 매 생성마다 AI에게 "응답 끝에 상태 블록을 붙여라"라고 지시해.
   AI가 붙인 `<scene_state>` 블록(장소·복장·자세·접촉·이번 턴의 전개)을 확장이 파싱해서 저장하고, 화면에서는 지워서 안 보이게 해.
2. **주입** — 다음 생성 때 프롬프트에 이렇게 주입해:
   - 현재 장면 상태 (모순 금지: 벗은 옷 부활 금지, 순간이동 금지)
   - 최근 N턴의 전개 목록 (그대로든 말만 바꿔서든 반복 금지)
   - 진행 지시 (유지 / 자연스럽게 다음 단계 / 적극적으로 진도)
3. **보정** — AI가 상태 블록을 빼먹으면 보조 AI 호출로 최근 대화를 분석해서 상태를 다시 잡아. 수동 "상태 다시 분석" 버튼도 있어.

---

## 설치

1. SillyTavern 화면에서 퍼즐 아이콘 클릭
2. **Install Extension** 클릭
3. 아래 주소 붙여넣기:
   ```
   https://github.com/foreverharibo-boop/ttotto-nsfw
   ```
4. 설치 완료 → SillyTavern 새로고침

## 첫 설정

1. 확장 설정 패널(퍼즐 아이콘 → 또또NSFW) → **설정** 탭
2. **"모든 캐릭터는 성인입니다"** 체크 (필수)
3. **"현재 채팅에서 사용"** 체크 — NSFW 장면이 시작될 때 켜는 걸 추천해
4. 반복 금지 범위(기본 3턴)와 진행 속도를 취향대로 조절

보정 분석용 연결 프로필을 따로 지정하면 상태 보정에만 그 연결을 써. 저렴한 모델 추천.

---

## 장면 상태 탭

- **현재 장면 상태**: 장소와 인물별 복장·자세·접촉이 표시돼. 직접 수정하면 다음 생성부터 바로 반영돼.
- **최근 전개**: 반복 금지 목록에 올라간 전개들이 칩으로 표시돼. ×를 누르면 그 항목만 금지에서 빼.
- **주입문 보기**: 실제로 프롬프트에 들어가는 내용을 그대로 확인할 수 있어.
- **기록 비우기**: 이 채팅의 장면 기록을 전부 리셋해.

## 한계

- 또또와 마찬가지로 프롬프트 주입 방식이라, 모델이 지시를 무시할 수 있어. 그럴 땐 리롤하거나 상태를 손으로 고쳐줘.
- 상태 블록을 자주 빼먹는 모델이라면 "태그 누락 시 자동 보정"을 켜두는 걸 추천해 (보조 호출 비용은 발생).
- 그룹 채팅은 일단 동작은 하지만, 인물이 많으면 상태 정확도가 떨어질 수 있어.
