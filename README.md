# 🔞또또NSFW

NSFW 장면 **전용** 연속성 확장이야. 평소엔 유령처럼 조용히 있다가, 장면이 달아오르는 순간에만 나타나서 세 가지를 잡아줘:

- **상태 모순 금지** — 벗긴 옷이 다시 입혀지고, 자세·위치가 순간이동하는 것
- **직전 전개 반복 금지** — 방금 한 행위를 다음 턴에 처음 하는 것처럼 또 하는 것
- **진도 강제** — 같은 자리를 맴돌다 장면이 흐지부지 끝나는 것
- **선택형 슬로우번** — 단계마다 천천히 새로운 전개를 쌓고 급발진·조기 마무리를 막는 것

[또또](https://github.com/foreverharibo-boop/ttotto)의 자매 확장이지만 따로 설치해서 단독으로 동작해.
또또가 문장·표현 반복을 잡는다면, 또또NSFW는 전개·행위 반복과 상태 모순을 잡아. 둘이 겹치는 것 없이 상호 보완이야.

**성인(만 18세 이상) 캐릭터 전용이야.** 설정에서 "모든 캐릭터는 성인입니다" 확인에 체크해야 동작해.

## 어떻게 동작해?

### 평소 (일상 장면) — 완전 침묵 (스텔스, 기본)

프롬프트 주입 **제로**, AI 호출 **제로**, 흔적 **제로**.
확장이 브라우저 안에서 최근 메시지를 직접 스캔하며 NSFW 신호(표현·전개 패턴)를 점수로만 매겨. 일상 장면에는 아무것도 안 해.

감지 민감도(민감/보통/둔감)를 고를 수 있고, 자주 쓰는 표현을 커스텀 키워드로 추가하면 감지가 더 정확해져.
모델이 온도를 직접 보고하게 하는 "온도 자동" 모드(매턴 한 줄 요청)도 옵션으로 있어.

### 장면이 달아오르면 — 자동 개입

1. NSFW 신호가 기준을 넘는 순간 자동 무장 + 보조 AI가 최근 대화를 읽어 장소·복장·자세·접촉을 즉시 백필
2. 매 생성마다 프롬프트에 주입:
   - **현재 장면 상태** (모순 금지: 벗은 옷 부활 금지, 순간이동 금지)
   - **최근 N턴 전개 목록** (말만 바꿔서 반복해도 반복임)
   - **다음 전개 힌트** (AI가 스스로 제안한 새 전개 후보)
   - **진행 지시** (유지 / 자연스럽게 다음 단계 / 적극적으로)
3. AI 응답 끝의 `<scene_state>` 블록을 파싱해 저장하고 화면에서는 제거
4. 장면이 식으면 (온도 2↓) 다시 초경량 감시로 복귀

### 🔥 슬로우번 (선택 기능)

설정에서 슬로우번을 켜면 기존의 한 줄짜리 진행 속도 지시 대신 6단계 진행 관리가 적용돼.

1. 긴장과 분위기 형성
2. 시선·말·거리 좁히기
3. 가벼운 접촉
4. 접촉과 반응 심화
5. 본격적인 전개
6. 마무리 허용

- 강도에 따라 각 단계에 최소 1·2·3턴 머문 뒤 자연스러울 때만 다음 단계로 넘어가
- 한 답변에서 한 단계 이상 건너뛰거나, 중간 과정을 생략·요약하거나, 6단계 전에 임의로 장면을 끝내지 않게 지시해
- 같은 행동을 늘여 쓰는 방식이 아니라 새로운 대사·감정·반응·감각을 쌓도록 지시해
- 장면 상태 탭에서 현재 단계를 이전·다음으로 조절하거나 고정할 수 있고, 다시 자동 감지로 돌릴 수 있어
- "사용자 주도 전개 허용"이 켜져 있으면 사용자가 먼저 명확하게 진행한 행동은 단계 제한보다 우선해

슬로우번을 끄면 기존 진행 속도 설정(자동/유지/자연스럽게/적극적으로)이 그대로 동작해.

수동 모드로 바꾸면 채팅 토글이 곧 개입 스위치가 돼.

### 주입은 영어, 화면은 한국어

모델이 상태 값을 `"English || 한국어"` 쌍으로 보고해서, 프롬프트 주입에는 영어만(지시 이행률·토큰 효율), 확장 패널 표시에는 한국어만 쓰여.

### 주입문 다이어트

- 태그에는 의미 있는 전개만 2~4개 기록 (간식·담요·리모컨 같은 잡동사니 제외)
- 같은 전개가 여러 턴에 중복 기록되면 최신 것만 유지
- 반복 금지 목록 총량 상한 (기본 15개, 5~30 조절) — 넘치면 오래된 것부터 자동 제외
- 실제 주입 내용은 "주입문 보기"로 글자 수까지 그대로 확인 가능

## 설치

1. SillyTavern 화면에서 퍼즐 아이콘 클릭
2. **Install Extension** 클릭
3. 아래 주소 붙여넣기:
   ```
   https://github.com/foreverharibo-boop/ttotto-nsfw
   ```
4. 설치 완료 → SillyTavern 새로고침

## 추천 세팅 (이대로만 하면 됨)

1. 확장 설정 패널(퍼즐 아이콘 → 또또NSFW) → **설정** 탭
2. **"모든 캐릭터는 성인입니다"** 체크 (필수)
3. **"현재 채팅에서 사용"** 체크 — 롤플레이 채팅에서는 그냥 항상 켜둬
4. 개입 방식은 기본값인 **스텔스 자동** 그대로

끝. 이러면 켜고 끄는 걸 신경 쓸 필요 없이, NSFW 장면에서만 알아서 개입해.

보정 분석용 연결 프로필을 따로 지정하면 상태 분석에만 그 연결을 써 (메인 연결과 완전히 독립, 메인 프로필은 절대 안 건드림). 저렴한 모델 추천.

## 장면 상태 탭

- **현재 장면 상태**: 장소·인물별 복장·자세·접촉 + 온도 배지. 직접 수정하면 다음 생성부터 바로 반영
- **최근 전개**: 반복 금지 목록. ×를 누르면 그 항목만 금지에서 제외
- **다음 전개 후보**: AI가 제안한 새 전개 (파란 칩). ×로 제안에서 제외 가능
- **상태 다시 분석**: 보조 AI로 상태를 수동 재구성
- **주입문 보기 / 기록 비우기**

## 한계

- 프롬프트 주입 방식이라 모델이 지시를 무시할 수 있어. 그럴 땐 리롤하거나 상태를 손으로 고쳐줘.
- 상태 블록을 자주 빼먹는 모델이라면 "태그 누락 시 자동 보정"을 켜두는 걸 추천해 (보조 호출 비용 발생).
- 같은 그룹 채팅 안에 이름이 완전히 같은 캐릭터 둘이 있으면 상태가 한 칸으로 합쳐져.
